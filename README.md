## Contenido

- Presentación personal y perfil profesional.
- Sección de habilidades y ecosistema técnico.
- Apartados de proyectos y reconocimientos.
- Enlaces a perfiles sociales y GitHub.
- Acceso al archivo PDF del CV incluido en el repositorio.
- Navegación por secciones de la página.
- Diseño personalizado con CSS e iconografía.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Ejecutar localmente

No requiere instalación de dependencias.

```bash
git clone https://github.com/miguelagcz/miguel.com.git
cd miguel.com
```

Abre `index.html` en el navegador o utiliza Live Server.

## Objetivo

Centralizar la presentación de mi perfil y proyectos, practicar diseño web responsive y ofrecer a reclutadores una forma sencilla de conocer mi trabajo.

## Nota sobre el CV

El repositorio incluye una versión del CV en PDF. Si compartes el proyecto públicamente, verifica que el documento esté actualizado y que solo contenga información que deseas hacer pública.
